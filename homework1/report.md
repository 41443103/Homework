題目一

## 解題說明

本題要求用遞迴和非遞迴兩種方式計算Ackermann函數。

Ackermann函數定義:

$$
A(m,n)=
\begin{cases}
n+1 & m=0\\
A(m-1,1) & m>0,\ n=0\\
A(m-1,A(m,n-1)) & otherwise\\
\end{cases}
$$

### 解題策略

#### 遞迴
1. 使用遞迴函式依照定義拆解成三個判斷式 $m=0$, $n=0$,和其餘狀況($m>0$ $and$ $n>0$)。
2. 當 $m=0$時，返回 $n+1$ 作為遞迴的結束條件。
3. 當 $n=0$ 與其餘，則前者呼叫 $A(m-1,1)$，後者呼叫巢狀 $A(m-1, A(m,n-1))$。
4. 主程式輸入m和n並呼叫遞迴函式後，輸出計算結果。
#### 非遞迴
1. 使用動態陣列模擬堆疊，避免造成溢位。
2. 當空間不足時，將陣列空間乘2。
3. 使用while迴圈取出堆疊頂端top的 $m$ 值，依判斷式進行條件判斷後執行。
4. 遇到其餘情況的巢狀時，將依序放入堆疊。
5. 主程式輸入m和n後，進迴圈計算結束後，釋放動態記憶體並輸出結果。

## 程式實作

以下為主要程式碼：
#### 遞迴
```cpp
#include<iostream>
using namespace std;
long long A(long long m, long long n)
{
	if (m == 0)
	{
		return ++n;
	}
	else if (n == 0)
	{
		return A(m - 1, 1);
	}
	else
	{
		return A(m - 1, A(m, n - 1));
	}
}
int main()
{
	long long m, n;
	cin >> m >> n;
	cout << A(m, n)<<endl;
	return 0;
}
```
#### 非遞迴
```cpp
#include<iostream>
using namespace std;
long long N(long long m, long long n)
{
    long long a = 1024; //初始空間2^10
    long long top = 0;
    long long* s = new long long[a];
    s[top] = m;
    top++;
    while (top > 0)
    {
        top--;
        m= s[top];
        if(m==0)
        {
            n++;
        }
        else if (n == 0)
        {
            if (top + 1 >= a) //空間不夠 *2
            {
                a *= 2;
                long long* news = new long long[a];
                for (long long i = 0; i < top; i++) {
                    news[i] = s[i];
                }
                delete[] s;
                s = news;
            }
            s[top] = m - 1;
            top++;
            n = 1;
        }
        else
        {
            if (top + 2 >= a) {
                a *= 2;
                long long* news = new long long[a];
                for (long long i = 0; i < top; ++i) {
                    news[i] = s[i];
                }
                delete[] s;
                s = news;
            }
            //A(m-1,(m,n-1))
            s[top] = m - 1;
            top++;
            s[top] = m;
            top++;
            n = n - 1;
        }
    }
    delete[] s;
    return n;
}
int main()
{
    long long m, n;
    cin >> m >> n;
    cout << N(m, n) << endl;
    return 0;
}
```

## 效能分析

1. 時間複雜度： $O(A(m, n))$。
2. 空間複雜度： $O(A(m, n))$，非遞迴較不容易產生溢位。

### 結論

1. 遞迴與非遞迴版本皆能正確且精確地計算出 Ackermann 在合法範圍內的數值。
2. 非遞迴版本透過動態陣列模擬堆疊並具備容量自動倍增機制，成功在主記憶體中完成狀態維護與展開。
3. 測試案例涵蓋了基礎邊界條件，驗證了程式的運算正確性
4. 同時涵蓋了極端條件，例如數值過大或輸入無效範圍時，因突破 long long 範圍或超越定義域而產生的極限與異常現象。

## 申論及開發報告

### 選擇遞迴與非遞迴的差異

#### 遞迴
1. 定義上直觀性
本身的數學定義即為巢狀遞迴結構，無損地將數學公式轉譯為程式碼，邏輯單純且直觀。
2. 依賴系統呼叫堆疊
​資料結構使用系統內建的呼叫堆疊
，自動在背景記錄每一層的參數與返回位置，無須手動編寫記憶體管理程式碼。
3. 系統呼叫堆疊空間有限
當輸入數值較大（例如 $m > 4 ）時，堆疊會迅速耗盡，導致程式發生溢位而異常終止。

#### 非遞迴
1. 手動模擬堆疊
透過宣告一維陣列，並利用top與 while 來手動控制狀態的推入與彈出，還原巢狀遞迴的運算順序，相比遞迴較複雜。
2. 動態記憶體與空間擴增
無法預測總需要多少空間，堆疊空間即將用盡時，自動將陣列容量乘以 2，並將舊資料移到新陣列中，兼具彈性與效率。
3. ​提升系統強固性與安全性
將記憶體從受限的系統呼叫堆疊轉移至動態陣列，繞過了系統預設的堆疊大小限制，降低因過度遞迴而崩潰的風險。

無論採用遞迴或非遞迴，兩者由於 Ackermann 函數的數值成長呈爆炸性，當輸入 m 稍大時，必然會面臨整數型態的溢位極限。因此，非遞迴架構的核心在於使程式在合法範圍內運行得更為穩定。

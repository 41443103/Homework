## 題目一

## 解題說明

本題要求用遞迴和非遞迴兩種方式計算Ackermann函數。

Ackermann函數定義:

$$
A(m,n)=
\begin{cases}
n+1 & m=0\\
A(m-1,1) & m>0,\ n=0\\
A(m-1,A(m,n-1)) & otherwise\\
\end{cases}
$$

### 解題策略

#### 遞迴
1. 使用遞迴函式依照定義拆解成三個判斷式 $m=0$, $n=0$,和其餘狀況($m>0$ $and$ $n>0$)。
2. 當 $m=0$時，返回 $n+1$ 作為遞迴的結束條件。
3. 當 $n=0$ 與其餘，則前者呼叫 $A(m-1,1)$，後者呼叫巢狀 $A(m-1, A(m,n-1))$。
4. 主程式輸入m和n並呼叫遞迴函式後，輸出計算結果。
#### 非遞迴
1. 使用動態陣列模擬堆疊，避免造成溢位。
2. 當空間不足時，將陣列空間乘2。
3. 使用while迴圈取出堆疊頂端top的 $m$ 值，依判斷式進行條件判斷後執行。
4. 遇到其餘情況的巢狀時，將依序放入堆疊。
5. 主程式輸入m和n後，進迴圈計算結束後，釋放動態記憶體並輸出結果。

## 程式實作

以下為主要程式碼：
#### 遞迴
```cpp
#include<iostream>
using namespace std;
long long A(long long m, long long n)
{
	if (m == 0)
	{
		return ++n;
	}
	else if (n == 0)
	{
		return A(m - 1, 1);
	}
	else
	{
		return A(m - 1, A(m, n - 1));
	}
}
int main()
{
	long long m, n;
	cin >> m >> n;
	cout << A(m, n)<<endl;
	return 0;
}
```
#### 非遞迴
```cpp
#include<iostream>
using namespace std;
long long N(long long m, long long n)
{
    long long a = 1024; //初始空間2^10
    long long top = 0;
    long long* s = new long long[a];
    s[top] = m;
    top++;
    while (top > 0)
    {
        top--;
        m= s[top];
        if(m==0)
        {
            n++;
        }
        else if (n == 0)
        {
            if (top + 1 >= a) //空間不夠 *2
            {
                a *= 2;
                long long* news = new long long[a];
                for (long long i = 0; i < top; i++) {
                    news[i] = s[i];
                }
                delete[] s;
                s = news;
            }
            s[top] = m - 1;
            top++;
            n = 1;
        }
        else
        {
            if (top + 2 >= a) {
                a *= 2;
                long long* news = new long long[a];
                for (long long i = 0; i < top; ++i) {
                    news[i] = s[i];
                }
                delete[] s;
                s = news;
            }
            //A(m-1,(m,n-1))
            s[top] = m - 1;
            top++;
            s[top] = m;
            top++;
            n = n - 1;
        }
    }
    delete[] s;
    return n;
}
int main()
{
    long long m, n;
    cin >> m >> n;
    cout << N(m, n) << endl;
    return 0;
}
```

## 效能分析

#### 遞迴
1. 空間複雜度：當 m, n 較小時（ m=3, n=3），遞迴層數可控；當 m, n 較大時，遞迴層數會極速膨脹，導致 Stack Overflow。m≥4 時，空間複雜度超越 $O(2ⁿ)$   
2. 時間複雜度：對於較小 m，姑且還能計算 ，但m=4後，複雜度超過指數級，遠大於 $O(2ⁿ)$ 。
#### 遞迴
1. 空間複雜度：m=3 時，空間複雜度 $O(n)$ ；m=4 時，空間複雜度 $O(2^n)$ ；m≥5 時，空間複雜度超越 O(2^(2^(...2^n)))（n層）
2. 時間複雜度：對於 m=3，複雜度約 $O(2^n)$ ；m=4，複雜度約 O(2^(2^(...2^n))) （n 層）。實際上，計算 Ackermann(4, 2) 就需要幾億次操作。

## 申論及開發報告

### 選擇遞迴與非遞迴的差異

#### 遞迴
1. 定義上直觀性
本身的數學定義即為巢狀遞迴結構，無損地將數學公式轉譯為程式碼，邏輯單純且直觀。
2. 依賴系統呼叫堆疊
​資料結構使用系統內建的呼叫堆疊
，自動在背景記錄每一層的參數與返回位置，無須手動編寫記憶體管理程式碼。
3. 系統呼叫堆疊空間有限
當輸入數值較大（例如 $m > 4 ）時，堆疊會迅速耗盡，導致程式發生溢位而異常終止。

#### 非遞迴
1. 手動模擬堆疊
透過宣告一維陣列，並利用top與 while 來手動控制狀態的推入與彈出，還原巢狀遞迴的運算順序，相比遞迴較複雜。
2. 動態記憶體與空間擴增
無法預測總需要多少空間，堆疊空間即將用盡時，自動將陣列容量乘以 2，並將舊資料移到新陣列中，兼具彈性與效率。
3. ​提升系統強固性與安全性
將記憶體從受限的系統呼叫堆疊轉移至動態陣列，繞過了系統預設的堆疊大小限制，降低因過度遞迴而崩潰的風險。

無論採用遞迴或非遞迴，兩者由於 Ackermann 函數的數值成長呈爆炸性，當輸入 m 稍大時，必然會面臨整數型態的溢位極限。因此，非遞迴架構的核心在於使程式在合法範圍內運行得更為穩定。


## 題目二
## 解題說明

本題要求​給定個有 $n$個元素的集合 $S$，並輸出所有可能子集所組成的冪集合。

### 解題策略

1. 對每個元素進行兩種選擇，不加入當前元素，或加入當前元素進入下一個子問題。
2. 條件中止值為 a 等於集合大小 n 時，即完成一個子集的組合，直接輸出結果並返回。
3. 由使用者輸入集合大小與內容，配置動態陣列儲存資料，呼叫遞迴函式後釋放記憶體。

## 程式實作

以下為主要程式碼：
#### 遞迴
```cpp
#include <iostream>
#include <string>
using namespace std;
void powereset(string A[], string s[], int a, int n, int b)
{    
    if (a==n) 
    {
        cout << "{";
        for (int j=0; j<b; j++) 
        {
            cout << s[j];
            if (j!=b-1) cout << ",";
        }
        cout << "}" << endl;
        return ;
    }
    powereset(A, s, a + 1, n, b); // 不加當前 A[i]，處理下一個元素
    s[b]=A[a]; // 加入當前A[i]到子集
    powereset(A, s, a + 1, n, b + 1); // 處理下一個元素
}

int main() {
    int n;
    cout<<"n:";
    cin>>n;
    string* A=new string[n];
    string* s=new string[n];
    cout<<"集合元素 : ";
    for (int i=0; i<n;i++) 
    {
        cin >> A[i];
    }
    cout << "集合的冪集為:" << endl;
    powereset(A, s, 0, n, 0);
    delete[] A;
    delete[] s;
    return 0;
}
```

## 效能分析

1. 空間複雜度： $O(n)$
2. 時間複雜度： $O(n*2^n)$

## 測試與驗證

### 測試案例

|----------|--------------|--------------|----------|----------|
| 測試一   | $n = 1$      | a      | () (a)       | () (a)       |
| 測試二   | $n = 2$      | ab     |() (b) (a) (a,b)  | () (b) (a) (a,b) |
| 測試三   | $n = 3$      | abc    | () (c) (b) (b,c) (a) (a,c) (a,b) (a,b,c) | () (c) (b) (b,c) (a) (a,c) (a,b) (a,b,c) |

### 結論

1. 程式能正確生成並列舉出給定集合的所有冪集（Power Set）組合。
2. 透過遞迴與「包含或不包含」的決策樹概念，結合動態記憶體配置與釋放，確保程式在執行過程中的資料正確性與記憶體安全。
3. 時間複雜度為 $O(2^n)$，能有效處理一般規模的集合，但在 $n$值過大時，輸出與遞迴次數會呈指數級成長，較沒效率。

## 申論及開發報告

### 選擇遞迴與動態陣列的原因
使用遞迴與動態陣列來計算集合冪集（Power Set）的主要原因如下：

 1. 透過參數記錄當前處理的索引與子集長度，使程式邏輯與遞迴終止條件（$a == n$）明確清晰。
 2. 使用遞迴來模擬「包含與不包含」的二元決策樹，將 $n$ 個元素的冪集問題拆解為逐個元素取捨的子問題，完美對應 $2^n$ 種子集組合。
 3. 利用動態陣列依據使用者輸入的集合大小 $n$ 配置記憶體，確保資源妥善利用並避免空間浪費。
